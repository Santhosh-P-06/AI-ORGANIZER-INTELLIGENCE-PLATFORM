# Project Stack

This project is aligned with the development requirements in the provided image:

- Frontend: Next.js App Router for the web application, student dashboard, event discovery interface, and AI recommendation displays.
- Backend: Node.js through Next.js route handlers for API development, user/event operations, event processing, and AI integration services.
- Database: PostgreSQL schema for users, events, registrations, interactions, recommendations, analytics, webhook receipts, and automation runs.
- Mobile application: Flutter scaffold prepared for Android/iOS cross-platform access to the same REST API.
- UI/UX design: Figma handoff folder with design-token and flow guidance.
- Automation: n8n webhook topics and workflow starter for registration, attendance, panels, certificates, and event insights.
