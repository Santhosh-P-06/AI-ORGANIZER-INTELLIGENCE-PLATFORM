# Figma Handoff Notes

Use Figma for these screens and flows:

- User journey: organiser creates event -> AI generates form/agenda -> registrations open -> attendance -> panel allocation -> certificates -> analytics.
- Wireframes: organiser control center, student dashboard, volunteer QR flow, public certificate verification, n8n automation hub.
- Prototype states: empty event, published event, live event, completed event, failed automation, successful certificate dispatch.
- Responsive interfaces: desktop dashboard, tablet volunteer desk, mobile student event discovery.

Keep component names aligned with the code modules in `src/modules` so design and engineering stay easy to map.
